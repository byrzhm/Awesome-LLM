# Code Language Models

Code pretraining and coding workloads, collected from the repository's existing milestone and model resources.

## Foundational Paper

- [Evaluating Large Language Models Trained on Code](https://arxiv.org/abs/2107.03374) - Codex and the HumanEval benchmark for evaluating generated programs.

## Models and Research Collections

- [Awesome-Code-LLM](https://github.com/huybery/Awesome-Code-LLM) - Research resources for code language models.
- [StarCoder](https://huggingface.co/collections/bigcode/%E2%AD%90-starcoder-64f9bd5740eb5daaeb81dbec) and [StarCoder2](https://huggingface.co/collections/bigcode/starcoder2-65de6da6e87db3383572be1a) - Open code models from BigCode.
- [DeepSeek-Coder-V2](https://github.com/deepseek-ai/DeepSeek-Coder-V2) - Code-oriented MoE models.
